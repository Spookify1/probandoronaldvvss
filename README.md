# Bot de Discord Básico

Bot simple hecho con [discord.js](https://discord.js.org/).

## Configuración

1. Instala las dependencias:
   ```
   npm install
   ```
2. Copia `.env.example` a `.env` y coloca tu token del bot:
   ```
   DISCORD_TOKEN=tu_token_aqui
   ```
3. Ejecuta el bot:
   ```
   npm start
   ```

## Comandos

- `!ping` → responde "¡Pong!"
- `!hola` → saluda al usuario
